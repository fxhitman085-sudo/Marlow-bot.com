Need to Know

Frequently asked questions.

A few useful details to help you get started with MARLOW.

What is MARLOW?
MARLOW is a Discord bot. Its available commands and capabilities can be explored through Discord after inviting it to a server.
How do I invite MARLOW?
Use any of the Add to Discord buttons on this website. Select a server where you have permission to add bots, review the requested permissions, and follow Discord's authorization steps.
Is MARLOW free?
This website does not establish MARLOW's pricing or subscription terms. Check the official information provided by the developer for any applicable charges.
How do I get started after inviting MARLOW?
Complete Discord's authorization process and check MARLOW's available commands in your server. Only use commands that are actually available to you.
What permissions does MARLOW request?
The current invitation requests Administrator permission. This is a broad permission, so review it carefully before authorizing the bot.
Where can I read MARLOW's policies?
Visit the official MARLOW policies website to review the available policy documents.
