FAQ

Questions, answered.

A few useful details about MARLOW and this website.

What is MARLOW?
MARLOW is a Discord bot project. Use the official invite link to view its Discord authorization page.
How do I invite MARLOW?
Click any Invite MARLOW button on this website. Discord will ask you to sign in if necessary, choose a server, and review the requested permissions.
Is MARLOW free to add?
This website does not list a price or subscription. Check the official project information for any applicable terms.
Why does the invitation request Administrator permission?
The current invite link requests Administrator permission, which is broad access to the selected server. Review the permission screen carefully before approving it.
Where can I read the policies?
Visit the official MARLOW Policies website using the links in the Policies section below.
Who is behind MARLOW?
The project team listed on this website is Developer Raymon, Owner Fatab, and FATAB Team.
